Mission E6 · N°01
Déploiement Active Directory & GPO
Windows Server AD DS GPO DNS
↓ Télécharger

Cette mission consiste à déployer un environnement Windows Server complet avec Active Directory Domain Services, configurer le service DNS intégré, créer une structure d'unités d'organisation, gérer les utilisateurs et les groupes, puis appliquer des stratégies de groupe (GPO) pour sécuriser et uniformiser les postes clients.

1
Installation Windows Server et promotion en contrôleur de domaine Rôle AD DS · DNS intégré · Nom de domaine
2
Création de la structure Active Directory Unités d'organisation · Groupes de sécurité · Comptes utilisateurs
3
Configuration et déploiement des GPO Politique mot de passe · Mappage lecteurs · Restrictions utilisateurs
4
Jonction des postes clients et vérification Windows 10 joint au domaine · Connexion utilisateur · GPO appliquées

Mission E6 · N°02
Installation de GLPI sur Debian 13
GLPI Debian 13 LAMP MariaDB
↓ Télécharger

Cette mission consiste à déployer GLPI (Gestionnaire Libre de Parc Informatique) sur un serveur Debian 13. Elle couvre l'installation de la pile LAMP (Linux, Apache, MariaDB, PHP), la configuration du VirtualHost Apache, la création de la base de données et l'installation de l'agent GLPI pour l'inventaire automatique du parc informatique.

1
Installation Debian 13 et pile LAMP Apache2 · MariaDB · PHP 8.4 · Extensions PHP nécessaires
2
Préparation de la base de données Création BDD · Utilisateur SQL · Attribution des droits
3
Configuration Apache et installation GLPI VirtualHost · Modules proxy_fcgi · Installation via interface web
4
Agent GLPI et inventaire automatique Installation agent v1.16 · Machines visibles dans Parc → Ordinateurs
